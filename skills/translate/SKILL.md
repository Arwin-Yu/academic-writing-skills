# AI 论文中译英

输入为AI领域科研文章的中文段落或已有草稿。结合已有章节信息、上下文和术语表翻译，翻译时禁止使用破折号。

## 1. 翻译流程

- 提炼每段的核心论点、支撑信息和限定条件；操作说明围绕其目的组织。
- 据此重组英文，明确主体及句间关系。只补清原文能够确定的逻辑，不新增因果、动机或结论。
- 每段围绕一个中心展开，避免技术介绍流水账。原文缺少技术与论点的联系时指出缺口，不编造解释。

## 2. 英文表达风格

- **优先使用简单句。** 每句承载一条主要信息，拆开层层嵌套的长句；需要表达条件、比较或限制时，保留必要的从句。
- **用常见、准确的词。** 优先使用直接的动词，减少名词化、冗余短语和华丽修饰，不为“学术感”使用生僻表达。
- **按自然英文语序表达。** 明确主语、动作和对象，避免逐词对应中文；主动与被动语态根据表达重点选择。
- **让衔接来自内容。** 保持术语与指代连贯，减少机械堆叠连接词，不强行套用固定句型。
- **保持原文语气。** 清楚表达作者的判断、程度和限定，不通过翻译添加强调、评价或解释。

## 3. 验证与补救

双向核对：**原文实质信息无遗漏，译文科学陈述均有原文依据。**统一技术术语，核对数值、符号、公式、引用及 LaTeX 结构。

发现语义偏移、术语漂移或格式损坏，修正后复核。原文歧义、矛盾或论证缺口无法依据现有信息解决时，标明位置并列为待确认项，不靠润色掩盖。

## 4. 交付

先交付英文正文，仅在必要时附简短中文说明。保留原有章节和段落结构；必要的拆并须说明。长文标明完成范围，不把未处理部分或待确认内容宣称为定稿。

不默认输出回译、逐句对照、多个版本或检查报告；用户另有要求时遵从。
