# Discussion：建议3段

Discussion向读者说明：结果意味着什么、为什么重要、可以用在哪里、接下来应做什么。它不是局限清单。按下列职责组织，每段通常4—8句，数量可随实际内容调整；不把每个箭头固定为一句。

| 段落 | 叙事逻辑线 |
| --- | --- |
| **D1. 主要发现及其边界（正负面合为一段）** | 提炼多项结果共同支持的核心认识 → 说明它为何不只是训练目标或实验设置的直接结果 → 指出最影响结论的一两项局限及其来源 → 说明这些局限限定了哪些说法。正面认识在前，局限随后，二者合计不超过一个段落。 |
| **D2. 意义与应用** | 说明这些认识对哪些应用场景或研究问题重要 → 解释它们在实际使用中带来什么改变（可靠性、成本、可检查性等） → 说明对相关方法设计或评价方式的一般启示。应用须依据研究材料，不把设想用途写成已验证效果。 |
| **D3. 后续工作** | 从D1中的局限或尚未回答的问题出发 → 提出具体方向 → 说明可能奏效的依据（可附引用）及检验方式。 |

写作要求：
- 正面与负面分析合计不超过一个段落；其余段落写意义、应用与后续工作，不再逐条展开局限。
- 不重复Results中的数字和统计细节；只保留支撑判断所需的一两个关键结果。Results已报告的限定语不在此逐条复述。
- 局限只选最影响结论的几项，并在D3中对应提出回应方向。
- 错误分析描述失败现象，Discussion解释其对结论的影响；决定核心结论的新实验应先在Results中报告。

引用重点：将本研究发现与已有证据联系，区分支持范围、替代解释与推测。应用意义与后续方向可引用文献说明依据，但不把推测写成新的实验事实。
