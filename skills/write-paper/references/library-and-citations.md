# 文献库与引用计划

本文件用于 `write-paper` 的建库、证据复用与引用检查。文献库是整篇论文的共同基础，续写单章时复用已有成果，不重新检索40篇。创建或修改技能、讨论模板时不启动文献调研。

## 1. 确定范围并形成入选库

先从用户要求、研究材料及已有稿件明确主题、目标任务、拟解决问题、关键词和检索范围；已有确认不重复询问，缺少关键信息时先补问。定位项目已有文献库和原文缓存，沿用用户或项目已确认的筛选约定。

`deepresearch` 可用时复用其检索、原文核验和记录流程；实际调用时遵守其适用约定。本文件可独立执行，不将其综述目录上限、特定会刊或引用门槛设为通用论文要求。

从 Google Scholar 检索关键词、英文同义词、任务与机制，追踪代表论文的参考文献和后续引用，同时查看近期进展。入口不可用时改用 Semantic Scholar 或 OpenAlex，结合 DBLP、官方论文集及作者原文核对身份。记录查询、日期、实际查看范围和缺口；无新路径时停止重复尝试，不凭记忆补论文。

正文起草前，入选库须有不少于40篇相关、通过适用筛选且完成必要原文核验的独立文献，覆盖背景、代表方案、最接近工作、技术基础和近期进展。预印本与对应发表版合并计数；期刊扩展版先核对是否属于同一工作。跨章节复用不重复计数，待核验、未选用和排除记录不计入入选库，不为数量扩大到无关主题。

## 2. 逐篇理解并记录依据

每篇入选文献分别记录五项，不能用整段摘要或“本章用途”代替：

| 记录项 | 内容与主要阅读位置 |
| --- | --- |
| 研究问题 | 具体任务、困难与问题条件；优先摘要，不足时补引言。 |
| 动机 | 现有不足、解决理由及后果；优先摘要，不足时补引言，与研究问题分开。 |
| 方法 | 核心思路、关键操作及作用依据；以方法、图式和公式为主，讨论与结论补充。 |
| 局限性 | 假设、条件、失败与剩余问题；查方法、讨论和结论，实际失败或性能边界核对实验。 |
| 贡献 | 作者声称的新方法、理论、数据或发现；优先引言末，效果核对实验，理论结论核对推导。 |

保留作者、题名、版本、链接、筛选依据及实际阅读范围。每项概述关联证据ID；证据含具体陈述、原文简短转述、章节/页码/图表公式位置、条件和核验状态。贡献声明不是效果验证，作者报告、实验观察与本文解释分清；`verified` 仅表示原文支持对应陈述，不表示独立复现。

“未取得所需章节”与“在已读范围内未找到陈述”分开，未知内容留缺。若缺口影响拟采用主张，定向补读或收窄主张；不把未报告写成不能实现，不以局部阅读冒称全文核验。

## 3. 逐篇预分配正文引用

每篇入选文献在写作前至少分配一个有实际用途的引用位置，落实到章节、稳定段落ID和具体主张；同篇可支持多个位置。引用计划至少包含：

| 内容 | 要求 |
| --- | --- |
| 文献ID、引用键 | 对应唯一文献及实际使用版本，复用已有标识。 |
| 计划位置 | 章节与段落ID；段落标识由模板或现有稿件确定。 |
| 具体主张与用途 | 写出拟支持、反驳、限定、溯源或比较的陈述。 |
| 原文依据 | 对应证据ID、位置与适用条件，不能只有论文标题。 |
| 实际引用与状态 | 起草后记录实际段落及相邻陈述，区分已分配、已引用、待修复。 |

沿用实际目录，以 `references.md` 展示逐篇记录与引用计划，`references.json` 保存同一组信息。兼容已有 `problem_analysis` 五项、`evidence`、`chapter_use` 与 `outline.argument`；计划附在相应段落记录中，不为此改造整套库或重复存储论文。正文、计划和证据变化时同步更新。

## 4. 按章节取用

Introduction重点用文献建立问题价值、已有进展及研究缺口；Related Work综合共同问题、技术基础与最接近工作的差异。Method核对借鉴方法和设计前提，Results核对数据集、指标、基线和实验协议来源，Discussion联系已有发现与边界。Conclusion只收束已论证认识，不为分配文献增加新主张。各章不设平均配额。

组织每段前读取对应计划和所需证据，引用紧邻真正支持的陈述，不把来源整理成逐篇技术流水账。本文方法和实验结论须有自己的材料，不能用文献结果代替。新增引用先核验、入库和分配；段落合并、拆分或论点变化时重新映射。

## 5. 区分章节检查与全篇检查

单章或单段任务只核查本轮计划引用是否实际落实、证据是否匹配，报告本章完成情况；其余章节仍待引用不能误判本章失败，也不能据此宣称整篇完成。

最终整篇须满足：入选库不少于40篇；每篇至少一个预分配位置，并在正文实际引用至少一次；未分配与未引用的入选文献均为零。只列入参考文献表、通过 `nocite` 加入或仅标记“已引用”不算落实，须对照实际正文及支持关系。

漏引就补足有依据的论述或调整位置；证据不支持时修正主张、改配适当位置或替换文献，替换后仍满足数量和引用要求，不能无关挂引。数量不足、核心证据缺失或引用仍未落实时保留已完成部分，列明缺口与影响，不能标记整篇完成。
