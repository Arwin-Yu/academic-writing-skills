# Related Work：建议3段

根据当前段落任务采用下列叙事逻辑，每段通常4—8句，数量可随实际内容调整；不把每个箭头固定为一句。段落ID用于引用分配，重组时同步迁移映射。

| 段落 | 叙事逻辑线 |
| --- | --- |
| **R1. 同一问题下的已有方案** | 确定共同问题或比较维度 → 综合代表方法的解决思路 → 比较能力、条件与代价 → 归纳已解决部分及剩余问题。 |
| **R2. 相关技术基础** | 指出与本文有关的关键思想及其作用 → 说明已有研究如何运用 → 解释原有条件与本文任务的差异 → 明确本文继承、调整或重新组合了什么。 |
| **R3. 与最接近工作的关系** | 说明直接比较对象的选择依据 → 交代共享的问题设定或技术基础 → 明确本文改变的设计、假设或对象 → 界定需要验证的实质差异。 |

按问题和方法关系组织引用，避免逐篇介绍技术。重复引用同一文献时，应承担不同且必要的论证作用。

引用重点：围绕共同问题综合已有文献，说明比较条件和最接近工作。不能因单篇局限概括整个领域，不将年份先后写成继承或针对性改进。
