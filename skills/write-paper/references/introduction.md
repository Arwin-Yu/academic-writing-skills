# Introduction：建议5段

根据当前段落任务采用下列叙事逻辑，每段通常4—8句，数量可随实际内容调整；不把每个箭头固定为一句。段落ID用于引用分配，重组时同步迁移映射。

| 段落 | 叙事逻辑线 |
| --- | --- |
| **I1. 研究问题及价值** | 指出什么任务、什么条件下存在什么具体问题 → 说明解决它需要获得的能力或满足的要求 → 交代未解决的实际后果 → 明确本文聚焦的问题与范围。 |
| **I2. 已有研究与缺口** | 概括已有方法的主要思路及已实现的能力 → 指出与本文直接相关的不足 → 说明这项不足何时、为何成为障碍。 |
| **I3. 关键困难与设计洞见** | 分析解决缺口必须处理的困难 → 解释其中的约束、依赖或冲突 → 提出有依据的观察或假设 → 形成需要检验的设计判断。 |
| **I4. 本文方法概览** | 概括核心思路 → 说明关键设计改变了什么 → 解释它如何回应上述困难 → 交代各部分怎样配合形成完整方法。 |
| **I5. 贡献与验证** | 陈述主要研究成果 → 明确相对已有工作的新增内容 → 概括关键实验发现 → 限定贡献成立的条件、范围或代价。 |

Introduction建立研究缺口与本文回应；详细文献比较留给Related Work。

引用重点：I1—I3用原文建立问题价值、已有能力与研究缺口；I4—I5说明本文设计和贡献，已验证效果依据本研究记录。不要把单篇局限扩成领域共识，也不强造额外贡献。
