# Results：建议6段

根据当前段落任务采用下列叙事逻辑，每段通常4—8句，数量可随实际内容调整；不把每个箭头固定为一句。段落ID用于模板组织；引用计划按大章节记录，实际写作时按论点选择引用。

| 段落 | 叙事逻辑线 |
| --- | --- |
| **E1. 实验设计** | 明确要检验的问题或假设 → 说明数据与划分为何适合 → 交代基线及比较条件 → 定义指标、重复实验和不确定性报告方式。 |
| **E2. 主要结果** | 直接提出核心发现 → 用关键数值或图表支撑 → 比较可比条件下的基线差异 → 限定结果能够支持的结论。 |
| **E3. 消融实验** | 指出要检验的设计选择 → 说明改变项与控制条件 → 报告结果变化 → 解释该对照支持什么、还不能排除什么。 |
| **E4. 泛化或稳健性** | 明确改变了哪些条件 → 说明测试方式 → 报告变化后的表现 → 界定已验证能力与尚未覆盖的范围。 |
| **E5. 成本与效果取舍** | 指出评估的成本 → 交代硬件、规模、计时范围和质量条件 → 展示成本与效果的关系 → 说明适合的预算或使用场景。 |
| **E6. 错误与失败模式** | 指出代表性或系统性失败 → 提供案例、统计或图示证据 → 说明发生条件 → 给出证据允许的直接解释。 |

Results优先回答“观察到了什么、支持到哪里”。不将消融自动写成完整机制证明，也不跨不一致的实验条件直接排名。

引用重点：核对数据集、指标、基线和协议来源；本文数值、消融和失败案例来自实际实验记录。缺少对应实验时列明缺口，不生成模板预设的结果。
