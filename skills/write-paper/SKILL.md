# write-paper

先整理不少于40篇入选文献并逐篇分配引用位置，再围绕本研究的段落论点组织正文。每篇入选文献须在最终正文中实际引用至少一次。修改或打包本技能不启动调研与论文写作。

## 1. 判断范围并选择章节模板

读取本轮要求、目标标题、大纲或草稿及必要上下文，判断当前任务是建库、配引、写作还是核查，以及要处理的章节和段落。优先依据用户明确范围，其次看稿件位置和内容承担的任务；只有不同解释会实质改变输出且无法判断时才询问。

写作时仅加载对应模板，并取其中与本次目标有关的段落逻辑；不默认扩写整章或加载全部模板。整篇任务分章使用，混合章节按各段的实际职责分别选择。

| 当前内容或请求 | 模板 | 默认段落标识 |
| --- | --- | --- |
| 引言、Introduction、Intro，问题价值与贡献定位 | [Introduction](references/introduction.md) | I1—I5 |
| 相关工作、Related Work，已有方法关系与比较 | [Related Work](references/related-work.md) | R1—R3 |
| 方法、Method、任务形式化、训练或实现过程 | [Method](references/method.md) | M1—M6 |
| 实验、Results、Experiments、Evaluation，设置、结果、消融与成本 | [Results](references/results.md) | E1—E6 |
| 讨论、Discussion、局限、结果含义与后续方向 | [Discussion](references/discussion.md) | D1—D3 |
| 结论、Conclusion、全文收束 | [Conclusion](references/conclusion.md) | C1 |

报告新实验观察用Results，解释已有发现的意义与边界用Discussion；“相关工作”属于原创论文的组成部分，不因含有review含义就转为综述写作。标题与内容不一致时按实际职责判断，沿用稿件标题并说明必要调整。

模板默认实证方法型论文，每段通常4—8句话，段数为建议。根据真实研究与篇幅取舍，不为填满模板创造第二创新、损失函数、训练步骤、实验或贡献。重组段落时保留或迁移稳定标识及引用映射。

## 2. 准备文献库与引用计划

建库、配引或核查引用时读取 [文献库与引用计划](references/library-and-citations.md)。开始正式正文前确认：至少40篇去重、相关、完成必要筛选和原文核验的入选文献；逐篇五项研究记录可用；每篇至少分配一个章节、段落及具体主张，并关联证据。

已有库和已确认范围直接复用，不每写一章就重新检索40篇。需要补建时优先使用可用的deepresearch调研与记录流程；不可用时按本包文献流程执行。主题、任务或检索范围尚不清楚时先补足，不能拿模板示例当作用户研究方向。借用文献调研流程时保留其适用筛选约定，不将综述目录安排直接套成原创论文结构。

Introduction与Related Work重点分配，其余章节按论证需要使用；同一文献可多处引用，不重复计数。文献库或分配计划未就绪时先完成准备或交付明确缺口，不冒称已满足写作前置条件。

## 3. 围绕段落论点起草

先由本段标题、大纲、草稿和上下文提炼一句核心判断，再按对应模板的叙事逻辑选材、重排和重写。主题名、论文名单和写作指令不能代替论点；定义与背景段明确要建立的认识即可。模板是组织依据，不将提示语逐条扩写进正文。

起草前读取本段已分配文献与原文依据；用它们支撑实际陈述并贴近主张引用。区分研究问题、已有不足、本文改变及对应证据；写清关键对象、操作、作用依据和条件，不能只列模块或执行步骤。首尾附有论点、段中仍逐篇或逐模块介绍，也属于技术流水账，须重新组织。

文献用于支撑背景、设计基础与比较；本文方法、实验和推导须来自用户材料或项目记录。没有实验数据不填性能数字，没有机制或理论依据不编解释。作者主张、实验观察、理论结果和本文分析分别表述；缺必要材料就标明具体缺口并停止扩写依赖它的结论。

缩短时删重复和旁支，保留论点、必要前提及证据条件；总结从已有论证推出。新增文献先核验、入库和分配，再引用；正文和计划变化后同步更新实际引用位置。

## 4. 核查、修复与交付

先不看提纲，只读正文与必要上下文，复述本段建立的判断、依据及与相邻段落的关系，再对照原文、研究记录和引用计划核查。按实际问题处理：

| 未通过的表现 | 修复方式 |
| --- | --- |
| 章节职责或论点不清，组织成技术介绍流水账 | 重新判断章节职责并选模板，明确核心判断，按问题、设计作用和证据关系重组选材；不能只补过渡词或泛泛总结。 |
| 必要前提缺失，方法作用或段间联系仍靠猜测 | 补入有依据的对象、条件和推理，或调整顺序；无依据则撤去推论并列出缺口，不凭经验补造。 |
| 事实、数字、比较或结论强度超出材料 | 定向核查原文或项目记录，修正、限定或删除不成立的主张，再复查受影响结论。 |
| 文献未分配、计划引用未落实或引文不支持相邻主张 | 对照分配表补写有证据的论述，修复引用位置或重新分配；确无用途则以合格文献替换，保持数量与覆盖要求。 |

章节任务核对本章已分配引用是否落实，其他章节的计划引用可保留待写；报告本章完成状态与全篇剩余项。整篇完成必须满足入选库不少于40篇、每篇均有分配且均在最终正文实际引用，未分配和未引用数量为零。仅列文献表、登记计划或堆放无关引文不算完成。

修改后复查受影响的正文、承接、证据与引用映射。无法在现有材料与授权范围内修复时交付可成立部分及具体缺口，不标为完整稿，也不删除已确认问题来规避失败。结构或脚本检查不能代替内容与引证判断。

交付正文及必要缺口，简述本次使用的章节模板和引用落实情况。用户只要正文时过程留在工作记录中，但影响正文成立的缺口仍须说明。沿用用户语言、篇幅、格式与已有项目约定；文件任务保留旧稿，只改授权范围，内容稳定后按项目需要处理引用排版、编译并查看修改页。
