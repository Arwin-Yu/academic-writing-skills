# write-paper

先整理不少于40篇入选文献并逐篇分配引用章节，再围绕本研究的段落论点组织正文。每篇入选文献须在最终正文中实际引用至少一次。修改或打包本技能不启动调研与论文写作。

## 1. 判断范围并选择章节模板

读取本轮要求、目标标题、大纲或草稿及必要上下文，判断当前任务是建库、配引、写作还是核查，以及要处理的章节和段落。优先依据用户明确范围，其次看稿件位置和内容承担的任务；只有不同解释会实质改变输出且无法判断时才询问。

写作时仅加载对应模板，并取其中与本次目标有关的段落逻辑；不默认扩写整章或加载全部模板。整篇任务分章使用，混合章节按各段的实际职责分别选择。

| 当前内容或请求 | 模板 | 默认段落标识 |
| --- | --- | --- |
| 引言、Introduction、Intro，问题价值与贡献定位 | [Introduction](references/introduction.md) | I1—I5 |
| 相关工作、Related Work，已有方法关系与比较 | [Related Work](references/related-work.md) | R1—R3 |
| 方法、Method、任务形式化、训练或实现过程 | [Method](references/method.md) | M1—M6 |
| 实验、Results、Experiments、Evaluation，设置、结果、消融与成本 | [Results](references/results.md) | E1—E6 |
| 讨论、Discussion、局限、结果含义与后续方向 | [Discussion](references/discussion.md) | D1—D3 |
| 结论、Conclusion、全文收束 | [Conclusion](references/conclusion.md) | C1 |

报告新实验观察用Results，解释已有发现的意义与边界用Discussion；“相关工作”属于原创论文的组成部分，不因含有review含义就转为综述写作。标题与内容不一致时按实际职责判断，沿用稿件标题并说明必要调整。

模板默认实证方法型论文，每段通常4—8句话，段数为建议。根据真实研究与篇幅取舍，不为填满模板创造第二创新、损失函数、训练步骤、实验或贡献。段落标识用于模板组织，引用计划按大章节维护。

## 2. 准备文献库与引用计划

建库、配引或核查引用时读取 [文献库与引用计划](references/library-and-citations.md)。开始正式正文前确认：至少40篇去重、相关、满足deepresearch统一准入门槛且完成原文核验的入选文献；逐篇五项研究记录可用；每篇至少预分配一个大章节，并记录用途与依据。

已有库和已确认范围直接复用，不每写一章就重新检索40篇。需要补建时优先使用可用的deepresearch调研与记录流程；不可用时按本包文献流程执行。主题、任务或检索范围尚不清楚时先补足，不能拿模板示例当作用户研究方向。本包独立执行时同样必须使用文献流程中列出的会刊、JIF和引用准入条件；综述目录安排不直接套成原创论文结构。

Introduction与Related Work重点分配，其余章节按论证需要使用；同一文献可多处引用，不重复计数。文献库或分配计划未就绪时先完成准备或交付明确缺口，不冒称已满足写作前置条件。

## 3. 起草与写作风格

由标题、大纲、草稿及上下文提炼本段核心判断，再按所选模板组织材料；主题、论文名单和写作指令不能代替论点。起草前从本章预分配文献中选取当前论点所需依据，引用紧邻实际主张，不沿提示语逐条扩写。

- **具体直述：** 明确主语、动作与对象，直接说明机制、发现或局限。新概念只补理解所需的定义与前提，已有上下文足够时不重复解释。
- **关系完整：** 对象、属性或分析层次变化时交代与当前论点的联系；必要前提须能从正文与上下文找到。不能用连接词跳过推理，也不能以模块名或步骤代替作用解释。
- **信息有效：** 删去空泛开场、重复总结及未增加信息的文献转述，保留必要证据归属。组织、选材与核查操作留在底稿；有实质内容的分类依据、范围说明和章节导航保留。缩短时删旁支，保留论点、关键前提和证据条件。
- **边界诚实：** 区分作者主张、实验观察、理论结果与本文解释。本文方法、实验和推导须有研究材料；不编数字、机制或贡献，不筛去相反结果维持原论点。比较保留任务、数据与运行条件差异，不由相关性或年份推出因果与改进关系。

首尾附有论点、段中仍逐篇或逐模块罗列，也属于技术流水账，须重组。缺必要材料时停止扩写依赖它的结论；新增文献先核验、入库和分配，跨章调整或引用用途变化后同步计划。

## 4. 验证、修复与交付

先不看提纲，只读最终正文与必要上下文，复述本段判断、依据及段间联系；不能借底稿补出未写明的前提。再对照原文、研究记录和引用计划核查，不能以自评“通过”代替验证。

| 未通过的表现 | 修复方式 |
| --- | --- |
| 读不出核心判断、必要前提缺失，或只是技术介绍流水账 | 明确论点，按实际职责选模板并重组；补清有依据的对象、作用和关系，不只添过渡词。无依据的推论撤去并列明缺口。 |
| 空泛、重复、无信息的转述或写作操作进入正文 | 删除或替换为具体陈述；保留必要归属、分类前提与范围说明，不凭关键词机械删句。 |
| 事实、比较或表述强度超过证据范围 | 定向核查原文与研究记录，补足条件、限定或修正判断；相反证据一并考虑，不能靠润色保留不成立的主张。 |
| 引用未分配、未落实或不支持相邻主张 | 对照分配表修复论述和引用位置，必要时重新分配或以合格文献替换，保持数量与覆盖要求。 |

修改后重读受影响的正文、承接与结论，并复核相关证据和引用映射；换措辞、缩句、引用存在或脚本通过均不等于问题已解决。无法继续修复时交付可成立部分及具体缺口，不标为完整稿，也不删除已确认问题规避失败。

单段任务检查本段实际引证，记录本章已引与待引文献；整章完成检查该章预分配引用是否落实，报告本章状态与全篇剩余项。整篇完成须有不少于40篇入选文献，每篇均有分配并在最终正文实际引用，未分配和未引用数量为零；仅列文献表、登记计划或无关挂引不算完成。

交付正文及必要缺口，简述所用模板、实际完成的内容与证据核查、引用落实情况；用户只要正文时过程留在工作记录中，但影响正文成立的缺口仍须说明。沿用用户语言、篇幅、格式与已有项目约定；文件任务保留旧稿，只改授权范围，内容核查后再排版、按项目需要编译并查看修改页，不用格式完成代替内容完成。
