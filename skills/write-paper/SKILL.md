# write-paper

整理或复用不少于40篇合格文献及章节候选用途，围绕本研究的问题与论证组织正文。预分配供选材使用，不要求库内每篇文献最终都被引用。修改或打包本技能不启动调研与论文写作；用户同时授权写作时按指定范围执行。

## 1. 判断范围并选择章节模板

读取本轮要求、目标标题、大纲或草稿及必要上下文，判断当前任务是建库、配引、写作还是核查，以及要处理的章节和段落。优先依据用户明确范围，其次看稿件位置和内容承担的任务；只有不同解释会实质改变输出且无法判断时才询问。

写作时仅加载对应模板，并取其中与本次目标有关的段落逻辑；不默认扩写整章或加载全部模板。整篇任务分章使用，混合章节按各段的实际职责分别选择。

用户提供认可或自行修改的版本时，将其作为本次组织与文风的参照：先读出各段在回答什么、解释展开到什么程度、如何介绍方法和结果，以及贡献的呈现形式，再起草。参照不是待自动纠正的草稿，也不是供逐句换词的母本；学习它的说明方式，用研究材料重新组织文字。仅翻译或指定替换时遵守该范围，不夹带重写。不同用户的参照不自动变成所有论文的固定格式。

写某一章前，先从稿件中已完成的章节提取：研究问题、提出的空白、已命名并定义的关键概念、主张的贡献。后续章节沿用同样的名称和问题来组织内容，比较维度优先使用前文概念；不另起术语，也不让章节脱离前文问题独立成篇。前文本身需要调整时，说明调整内容，不在后文悄悄改用另一套说法。

写作规则须与题材分开：跨论文可借鉴解释顺序、承接和表达方式，不移植参照中的研究对象、概念配对、技术步骤、实验设计、数值、引用或贡献类别。各论文依据自身问题和材料组织内容；一次校准中的实例与偏好不能自动成为其他论文的必需项。

| 当前内容或请求 | 模板 | 默认段落标识 |
| --- | --- | --- |
| 引言、Introduction、Intro，问题价值与贡献定位 | [Introduction](references/introduction.md) | I1—I5 |
| 相关工作、Related Work，已有方法关系与比较 | [Related Work](references/related-work.md) | R1—R3 |
| 方法、Method、任务形式化、训练或实现过程 | [Method](references/method.md) | M1—M6 |
| 实验、Results、Experiments、Evaluation，设置、结果、消融与成本 | [Results](references/results.md) | E1—E6 |
| 讨论、Discussion、局限、结果含义与后续方向 | [Discussion](references/discussion.md) | D1—D3 |
| 结论、Conclusion、全文收束 | [Conclusion](references/conclusion.md) | C1 |

报告新实验观察用Results，解释已有发现的意义与边界用Discussion；“相关工作”属于原创论文的组成部分，不因含有review含义就转为综述写作。标题与内容不一致时按实际职责判断，沿用稿件标题并说明必要调整。

模板提供常见研究论文的参考职责，段数和句数为建议。依据理论、实证、观察、系统、数据资源等实际研究类型，以及篇幅和投稿要求，合并、拆分或调整顺序；不默认每篇都有模型、训练或对照实验，不为填满模板创造方法、实验或贡献。段落标识用于模板组织，引用计划按大章节维护。

## 2. 准备文献库与引用计划

建库、配引、核查引用，以及起草或重写任何需要外部依据的正文时，读取 [文献库与引用计划](references/library-and-citations.md)。

写作前先定位项目已有文献库：deepresearch或本包产生的文献记录（如 `references.json`、`references.md`、引用计划文件，常见于稿件目录的 `temp/` 下）、项目BibTeX及原文缓存。只有实际查找后仍未发现才视为无库，并在交付时说明查找范围。用户限定写作材料（如仅依据摘要、大纲或草稿）时，限定的是正文内容来源，不排除文献库；只有用户明确禁止使用文献时才不配引。

开始正式正文前确认：至少40篇去重、相关、满足deepresearch统一准入门槛且完成原文核验的入选文献；逐篇五项研究记录可用；每篇至少预分配一个大章节，并记录用途与依据。

已有库和已确认范围直接复用，不每写一章就重新检索40篇。需要补建时优先使用可用的deepresearch调研与记录流程；不可用时按本包文献流程执行。主题、任务或检索范围尚不清楚时先补足，不能拿模板示例当作用户研究方向。本包独立执行时同样必须使用文献流程中列出的会刊、JIF和引用准入条件；综述目录安排不直接套成原创论文结构。

Introduction与Related Work重点预分配，其余章节按论证需要使用；同一文献可多处引用，不重复计数。预分配是供检索和扫描的候选池，不是择用比例或引用配额；是否采用只取决于第3节中具体主张的需要。未采用项保留记录，不算漏引，也不必转塞到其他章节。细则见文献流程。文献库或候选用途未就绪时先完成准备或交付明确缺口，不冒称已满足写作前置条件。

## 3. 起草与写作风格

所有章节均按“先论证、后配引、再扫库”三步起草，使段落顺序服从本文问题，而不是服从文献名单。

1. **依研究材料写出论证。** 由研究材料明确本章要回答的问题，确定各段推进的判断、成立所需的前提及其与前后段的联系，并写成正文。凡需外部依据的陈述先标 `[?]`，在紧邻的注释中写明需要哪类依据，例如因果证据、已有方法实例、数据集或指标出处、设计来源、反例或一致的已有发现。此时不按文献名单安排段落。
2. **逐处到文献库配引。** 对每个 `[?]`，在库中查找已核实证据确实支持该陈述的来源，而非仅主题相关：完全支持则引用；部分支持则收窄陈述至证据范围；证据相反则修改论证；库中没有则保留 `[?]` 及注释。主题相似、出现在分配表中或符合模板标题，均不足以成为引用理由。
3. **定稿前扫描本章候选。** 专门查找两类可能推翻正文的文献：最接近本文的已有工作，以及反例或限定条件。重点检查未标 `[?]` 却依赖文献状况的判断，如研究空白、“首次”或新颖性、方法优劣与通用性、与已有发现一致或矛盾。扫描到问题就修改论证或补引用，未发现则不为引用而增补内容。

各章节在第2、3步中取用文献的侧重见文献流程第4节。

起草时把这些判断写成读者能够跟上的解释：交代具体研究对象与条件，说明关键操作或推理，以及它为什么能够回应研究问题。不能用抽象的改进声明代替中间环节。介绍发现时交代证据来自什么、支持什么判断，再给必要的数字或其他具体依据；不把结果记录逐项压缩成一段。简洁应减少旁支和重复，保留理解研究所必需的展开；Introduction的细化方式见对应模板。

采用文献时说明它支持哪个前提、提供什么比较、限定什么范围或提出什么反证。多篇文献共同支撑一段时，交代共同问题、各自回答及其关系，再检查这些回答能否推出段落判断。互补证据和重复验证可以保留，不要求每篇承担独有的一步；也不能靠末尾补一句总结把偏题材料接回主线。

- **具体直述：** 明确主语、动作与对象，直接说明机制、发现或局限。新概念只补理解所需的定义与前提，已有上下文足够时不重复解释。
- **关系完整：** 对象、属性或分析层次变化时交代与当前论点的联系；必要前提须能从正文与上下文找到。不能用连接词跳过推理，也不能以模块名或步骤代替作用解释。
- **信息有效：** 删去空泛开场、重复总结及未增加信息的文献转述，保留必要证据归属。组织、选材与核查操作留在底稿；有实质内容的分类依据、范围说明和章节导航保留。缩短时删旁支，保留论点、关键前提和证据条件。
- **边界诚实：** 区分作者主张、实验观察、理论结果与本文解释。本文方法、实验和推导须有研究材料；不编数字、机制或贡献，不筛去相反结果维持原论点。比较保留任务、数据与运行条件差异，不由相关性或年份推出因果与改进关系。

首尾附有论点、段中仍逐篇或逐模块罗列，也属于技术流水账，须重组。`[?]` 只能在实际查过文献库仍无匹配来源后留在交付稿中，并保留说明所需依据的注释；不挂关系薄弱的引用，也不因缺引打断合理的论证组织。占位不表示主张已核实，未经核实的具体事实、数字、机制和比较结论不能靠占位写成定论。本文方法和结果按研究材料核查，不以外部引用替代。新增文献先核验、入库和记录用途，选用变化后同步计划。

## 4. 验证、修复与交付

分开检查论证与引证。先不看提纲和文献名单，只读正文，复述各段判断、必要前提及段间关系；不能借底稿补出未写明的联系。再按所用章节模板检查段落职责与信息次序，确认句间通顺之外，背景、问题和回应也在逐步展开。最后对照原文，核查每处实际引用是否支持相邻主张，并检查多条证据合起来能否推出本段结论。单篇转述准确、引用齐全或数量达标，都不能代替整段推理成立。

| 未通过的表现 | 修复方式 |
| --- | --- |
| 读不出核心判断、必要前提缺失，或只是技术介绍流水账 | 明确论点，按实际职责选模板并重组；补清有依据的对象、作用和关系，不只添过渡词。无依据的推论撤去并列明缺口。 |
| 章节、小节或比较维度与前文问题和概念对不上，或按文献类型分组而非按本文问题组织 | 从前文提取问题与概念，按本文问题依赖的前提重组；比较轴改用前文概念，不以单篇文献自带特点为轴。 |
| 删去某篇文献或某个模块的句子后，段落判断照样成立 | 说明该句只是罗列；改写为支撑、限定或反驳判断的一步，或删去。 |
| 每篇转述都正确，但文献之间只靠连接词或段尾总结串联 | 核对共同问题与推理对象，补足必要联系；偏离主线的材料撤出本段。研究A与B的证据不能直接承担A与C的结论。 |
| 空泛、重复、无信息的转述或写作操作进入正文 | 删除或替换为具体陈述；保留必要归属、分类前提与范围说明，不凭关键词机械删句。 |
| 结构符合模板，但仍用术语或指标压缩掉关键解释，与作者参照的说明方式不同 | 对照参照中同一职责的段落，找出遗漏的对象、操作、结果含义或贡献形式；补回必要解释，移走旁支。只换词或匹配句长不算修复。 |
| 事实、比较或表述强度超过证据范围 | 定向核查原文与研究记录，补足条件、限定或修正判断；相反证据一并考虑，不能靠润色保留不成立的主张。 |
| 实际引用不支持相邻主张，或需要依据的位置缺引 | 修正主张或改用匹配来源；暂缺来源则标 `[?]` 并记录。未采用的候选无需补引，不为配额扩写或机械改配。 |

修改后重读受影响的正文、承接与结论，并复核相关证据和引用映射；换措辞、缩句、引用存在或脚本通过均不等于问题已解决。无法继续修复时交付可成立部分及具体缺口，不标为完整稿，也不删除已确认问题规避失败。

用户要求验证技能效果时，将新生成稿与认可版本分开保存，逐段比较职责、承接、解释深度、措辞和信息取舍，并核对事实与引用；不能把参照的改写冒称独立生成，也不能以规则检查替代成稿比较。记录具体不匹配句及原因，修订对应规则后重新生成或修复并复查。未授权改正文时，测试稿和记录另存，保持用户文件不变；评价说明实际验证范围，不把一次相似输出说成今后必然一致。

单段任务检查本段实际引证；整章完成记录实际采用、未采用的候选及 `[?]` 位置。整篇核查文献库是否满足原定调研覆盖、实际采用引用是否准确、待补依据是否解决，不要求库内全部文献被引用，也不要求最终引用数量达到40篇。未采用不判失败；有 `[?]` 的稿件可作为待补引稿交付，但不得称引用核查已全部完成。影响主结论的证据缺失须明确说明。

交付正文及必要缺口，简述所用模板、实际完成的内容与证据核查、引用落实情况。引用落实须说明：所用文献库位置（或已查找的范围及无库结论）、从库中实际引用的文献、剩余 `[?]` 及各自所需依据、第3步扫描发现的最接近工作或反例及其处理；用户只要正文时过程留在工作记录中，但影响正文成立的缺口仍须说明。沿用用户语言、篇幅、格式与已有项目约定；文件任务保留旧稿，只改授权范围，内容核查后再排版、按项目需要编译并查看修改页，不用格式完成代替内容完成。
