# Academic writing skills

This repository packages three collaboratively refined skills: deepresearch, paperwrite, and rewrite.

When maintaining a skill, edit its instructions without starting the research or manuscript-writing workflow. Preserve verified-source requirements, user-authorized scope, and the distinction between a writing plan and manuscript prose.

Keep the three skill folders as siblings because their references are shared. Resolve paths from the file that contains the link. Do not hard-code a manuscript language, workstation path, or private paper library.

Only package resources required by the skills. Cite and review are planned, not implemented. Do not add placeholder skills or claim behavioral verification from syntax checks. Run the review checker on representative records if its behavior changes.

Preserve existing license declarations and document meaningful portability changes. Never include manuscript drafts, private literature records, credentials, or local session state in the release.
