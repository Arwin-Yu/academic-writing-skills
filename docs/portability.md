# 发布副本的适配说明

本次整理以现有 `deepresearch`、`paperwrite`、`rewrite` 草案为源，原项目中的源文件保持不变。

初次整理包含以下安装适配：

1. 把固定的文献库目录改为读取目标项目实际配置。正式库不存在时记录为空，不虚构文献库。
2. 由项目入口与已有文件定位TeX主稿，不把中文和英文文件名写死。
3. 沿用实际语言流程；中文优先或仅对话测试时，不自动修改英文稿或写入文件。
4. 项目已有写作约定和状态文件按需读取；没有这些文件时沿用对话与项目上下文，不要求用户先创建一套配置。
5. 保留跨技能相对链接，三个技能需要并列安装；改写检查器按技能实际位置调用。
6. 为三个技能增加最小UI元数据，默认保留自动发现能力。

关键词确认、目录不超过五节及确认步骤、原文核验、文献准入、段落解释逻辑、改写的六类关系和检查记录均保留。没有将本轮后续讨论自动扩展为新的写作禁令，也没有把尚未开发的cite/review补成空壳技能。

文献包仍存放在目标稿件目录的 `temp/章节ID/`，保留摘要、使用目的、阅读范围和原文位置；这些是执行技能时产生的数据，本仓库不附带原综述的文献包。

项目内相对路径以目标稿件根目录为基准，技能参考文件的相对链接以对应技能文件所在目录为基准。未启用的稿件语言无需占位文件。

## write-review 与论据衔接

新增 `write-review`，以段落或小节的核心判断组织综述正文，支持标题、大纲、文献材料及草稿输入；沿用项目实际语言、格式和写作范围，可独立安装。

`deepresearch` 第4节先逐篇记录研究问题、动机、方法、局限性和贡献，再建立综述判断与证据的映射；问题和动机优先摘要，贡献优先引言末尾，方法与局限按对应章节核实。第6节将五项分析与证据写入同一文献包的两种表示，沿用 `problem_analysis`、`evidence` 等字段与顶层格式，不另建文献库或改变第3节的选材门槛。原文核验说明供 `write-review` 等后续写作复用。

第7节将重复的整节推进、段间承接与句间解释检查合并，逐篇记录与来源核验一并检查；保留范围确认、综合判断和输出一致性的修复路径，区分原文材料的真实边界与尚未完成的核验，不再强制报告分阶段耗时。

`write-review` 的复核要求明确论点、解释、证据和段间关系不成立时的修复及交付边界；将技术介绍流水账列为不通过，不能仅加过渡词或泛泛总结。`paperwrite` 及其依赖保留供原有流程使用。

本轮仅更新技能与必要的安装、使用说明，不附带写作测试材料、论文正文、私人文献记录或本地会话状态。语法与链接检查不代表科学内容或可读性已经获认可。

## write-paper 与章节模板

新增独立的 `write-paper` 技能，入口根据用户范围、稿件位置和实际段落职责选择 Introduction、Related Work、Method、Results、Discussion 或 Conclusion 模板，按需读取。每段保留叙事逻辑线，4—8句及段数作为参考，不逐句套写；既有 `paperwrite` 继续保留。

文献库与引用计划作为正文前置成果：不少于40篇去重且完成必要核验的入选文献，逐篇保留五项研究分析和证据，并按大章节预分配引用、记录用途与依据；最终整篇每篇须有真实正文引用。章节交付只核对本章分配的引用，不误将未来章节未写记作本章失败，也不据此声称整篇完成。

技能包自带文献流程，可复用 `deepresearch` 和已有记录，无强制兄弟技能依赖；独立执行时仍强制采用与deepresearch相同的主会、最新JIF和单篇引用准入条件；引用计划精确到大章节，段落标识仅用于模板组织。发布文件仅含技能入口、六章模板、文献与配引说明和UI元数据，不附带试用材料或私人文献库。

`write-paper` 的通用写作约束由 `write-review` 提炼：具体直述、前提连续、信息有效和证据边界。入口同时定义基于最终正文的核查、修复与交付标准，不在六章模板中重复这些规则，也不增加对 `write-review` 的运行依赖。
